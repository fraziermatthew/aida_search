## Getting Started
This repository holds a conversational agent that can be imported into the DialogFlow ES framwork. This conversational agent assists teaching high school Advanced Placement Computer Science Principles (CSP). It is experimental and for research purposes only.

## Usage
You can interact with the conversational agent using this URL: https://bot.dialogflow.com/5b65b258-b361-4b80-ac73-f25372d03b2f
